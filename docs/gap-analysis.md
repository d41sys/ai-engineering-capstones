# Where the gap is: ragkit, minigpt, safegate, evalkit

Date: 2026-10-16. Every external claim links to a page I opened. `[INFERENCE]` = my reading, not verified. "Not found" = I searched and opened the pages cited; I did not do an exhaustive sweep.

## Bottom line

The crowded spot is capability (bigger corpora, bigger models, higher guard scores). The empty spot is **evidence discipline in the energy domain**: paired statistics, calibration, negative results, and real EU / NL energy data. All four repos already show this habit in their READMEs. A portfolio that reads "I measure when an LLM component in an energy system can be trusted, and I report when it cannot" beats portfolios that report one headline number.

## 3. Cross-repo story for a job application (AI engineering for energy)

One sentence: **"I build the evidence layer for LLM agents in energy systems: grounded answers over EU regulation, forecasts judged against honest baselines, gates on what the LLM hands to the optimiser, and statistics that say which differences are real."**

| Piece | Role in the story | Concrete artefact to show |
|---|---|---|
| ragkit | Agent must know EU rules and know when it does not | EU corpus + abstention AUROC/risk–coverage table |
| minigpt | Same from-scratch transformer, applied to NL prices, tested like a forecaster, not a demo | 12-fold DM table, honest verdict |
| safegate | Guard the formalization step | Text-guard vs spec-guard table on pilot attacks |
| evalkit | Shared statistical backbone for all three | Holm / power outputs cited in the other READMEs |
| FlexGridCyber (private) | The research question that motivates the rest | Pilot results (private repo, unpublished) |

Fit: the closest published work I opened ([agentic HEMS, 2026](https://arxiv.org/abs/2607.04569)) concludes every committed schedule needs an independent deterministic validator, and flags fabricated schedules; [NL→solver-ready power optimisation](https://arxiv.org/abs/2508.08147) uses validation-in-the-loop. Both are non-adversarial. Your portfolio sits one step later: what happens when the text feeding the formalizer is forged.

## 4. Order of work

1. evalkit resolvability layer first (others cite it). 2. minigpt backtest once M3 merges. 3. ragkit abstention. 4. safegate spec gate (depends on pilot rows). Total ≈ 12 working days.
